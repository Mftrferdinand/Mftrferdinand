## 👋 About

I build **agentic AI** and ship it. My work sits at the intersection of autonomous agents, developer tooling, and on-chain systems — from the framework that runs the agent to the surfaces people actually use.

I'm the founder of **Zerolinear**, an AI research lab, and the creator of **Zeline** — an open-source agentic AI framework that runs an autonomous agent with real tools, memory, skills, and messaging gateways.

## 🚀 What I'm building

- **[Zeline](https://github.com/Mftrferdinand/Zeline)** — open-source agentic AI framework. Model-agnostic, tool-first, runs anywhere (Termux, VPS, desktop). 200+ bundled skills, native MCP, multi-gateway (Telegram, WhatsApp, Discord, webhook).
- **[Zeline-Gateway](https://github.com/Mftrferdinand/Zeline-Gateway)** — transport and routing layer that connects the agent to every surface.
- **[Zeline-MCP](https://github.com/Mftrferdinand/Zeline-MCP)** — curated, spec-compliant MCP servers for Zeline and any MCP-compatible agent.
- **[Kedaicloud](https://kedaicloud.com)**, **[Web3 Addicter](https://web3addicter.com)** — Web3 infrastructure and community.
