## About

I’m **Mahesa F. Ferdinand**, leading Zerolinear and building developer-first tools for practical AI agents. My focus is on systems that remain in the developer’s control: portable across model providers, extensible with real tools, and deployable on infrastructure you own.

## Featured Project

### [Zeline](https://github.com/Mftrferdinand/Zeline) — Open-source agentic AI framework

**Zeline** is a flexible foundation for building AI agents that can reason, use tools, interact with external systems, and carry out complex, multi-step workflows.

It is model-agnostic and self-hostable. Developers can connect their preferred models and OpenAI- or Anthropic-compatible endpoints without having to rebuild the agent architecture.

**What Zeline includes**

- **Agent core & tool use** — an OpenAI-compatible agent loop with tool calling, an interactive CLI, and one-shot queries.
- **Memory & sessions** — persistent memory and conversation history that survive gateway restarts.
- **Real-world connections** — messaging gateways, web research, browser control, local files, APIs, scheduled jobs, and extensible custom tools.
- **Developer control** — open-source, model-agnostic, and built to run locally or on your own infrastructure.
